# Fuseco Endless Electrical Screensaver

An infinite 3D procedural electrical screensaver built with React 19, Three.js, and Vite. The camera glides through an endless interconnected electrical environment inspired by the industrial visual identity of Fuseco Australia—transitioning seamlessly across microscopic PCB circuit landscapes, industrial high-voltage fuse bays, busbar trenches, and transformer substations.

## Quick Start

### Install Dependencies
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Run Pure Logic Tests
```bash
npm test
```

### Production Build
```bash
npm run build
```

## Key Controls

- **Click / Tap Component**: Inspect detailed technical datasheet and electrical ratings.
- **Space**: Trigger high-voltage electrical arc discharge with synthesized procedural audio.
- **W / A / S / D or Arrow Keys**: Free flight manual navigation (in Manual Flight mode).
- **Q / E**: Descend / Ascend in Free Flight mode.
- **F**: Toggle Fullscreen.
- **Esc**: Close Component Datasheet / return to Screensaver.
- **H**: Toggle Zen Mode (hide HUD & telemetry overlay).
- **1 - 4**: Jump directly to electrical sectors:
  - `1`: Microscopic PCB Circuit Board
  - `2`: Industrial Fuse Bank (NH & BS88 Fuses)
  - `3`: Copper Busbar Trench
  - `4`: Heavy Transformer Substation
